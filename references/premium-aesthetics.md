# 高级风格配方库（Premium Style Recipes）

<!-- ui-alchemy: ignore-all (this file intentionally documents banned patterns like pure black/white as scan targets) -->

读于 Phase 1 选方向时。这里的每一套都是"看起来贵"的完整配方：情绪、字体、配色、布局签名、质感细节、反例。**选一套，不要混搭**；混搭是高级感的第一杀手。

用法：先读 [palette-system.md](palette-system.md) 学会取色，再按本库选风格方向。选定后立即用 `scripts/palette.py` 把主色展开成完整色阶 token，再写代码。

## 用色铁律（所有风格共用）

- **60 / 30 / 10**：六成中性表面，三成主调，一成强调。超过一成强调色的页面一定显得廉价。
- **一主一辅一强调**：页面永远只有一个主色、一个辅助色、一个强调色。第四个颜色只允许出现在状态语义（成功/危险）里。
- **表面有温度**：不用纯黑 `#000` / 纯白 `#fff`。深色表面带色相（偏绿/偏蓝/偏棕），浅色表面带暖或冷温度。
- **色温统一**：整页颜色要么都偏暖，要么都偏冷。暖色配冷灰是廉价感重灾区。

## 1. 暗夜香槟 Dark Champagne（奢华 / 餐饮 / 美妆）

- 情绪：安静、昂贵、克制。
- 字体：衬线 display（思源宋/Playfair 类）+ 无衬线正文。
- 配色：深黑棕底 `#171310`，香槟金 `#C9A86A`，骨白 `#F2EBDE`，表面 `#201A16` / `#2A231D`。
- 布局签名：大留白 + 单列居中 + 1px 金色细线分隔；图片统一暖光。
- 质感：圆角 4-8px（直边更贵），阴影低而柔，无渐变球。
- 反例：金色渐变文字、描金边框堆满、红金撞色。

## 2. 雾蓝晨光 Fog Blue（科技 / SaaS / 医疗）

- 情绪：冷静、专业、可信。
- 字体：几何无衬线（Outfit/Geist 类）display + 同系正文。
- 配色：雾蓝灰底 `#F3F6F8`，藏青主 `#1F3A5F`，冰蓝强调 `#5B8DB8`，深色表面 `#101820`。
- 布局签名：左文右数据，卡片浅色 + 1px 冷灰边，数据用 tabular-nums。
- 质感：圆角 12-16px，阴影带蓝色相，图表用主色单色系。
- 反例：蓝紫渐变、五颜六色的饼图、深蓝配荧光绿。

## 3. 编辑纸墨 Editorial Ink（杂志 / 文化 / 品牌叙事）

- 情绪：印刷质感、笃定、有观点。
- 字体：强衬线 display（思源宋/宋体）大字号 + 正文细无衬线。
- 配色：纸白 `#F7F3EA`，墨黑 `#1C1A17`，单一高饱和强调（朱红 `#C6402E` 或钴蓝 `#2456C4`）。
- 布局签名：不对称网格、超大标题、极细分割线、编号只有在承载顺序时才出现。
- 质感：几乎无圆角（0-4px），图片黑白或同色系，强调色只出现一次。
- 反例：渐变背景、圆角卡片泛滥、三种以上强调色。

## 4. 森野铜光 Forest Copper（咖啡 / 香氛 / 户外生活方式）

- 情绪：自然、醇厚、手工感。
- 字体：中文衬线 display + 无衬线正文（野径 H5 正在用）。
- 配色：深松绿 `#14231A`，苔绿 `#2B4A33`，骨白 `#F3ECDD`，铜 `#C98244`。
- 布局签名：编辑式分栏 + 签名数据卡（如烘焙曲线）+ 风味象限。
- 质感：圆角 16-20px，阴影带绿相，图片统一暖铜光。
- 反例：纯灰底 + 一个橙色按钮；森林绿配粉色。

## 5. 陶土南意 Terracotta（家居 / 生活方式 / 食器）

- 情绪：阳光、松弛、地中海。
- 字体：圆润无衬线 display + 正文无衬线。
- 配色：陶土 `#C0632E`，奶白 `#F7F0E4`，橄榄 `#6B7A45`，深棕 `#3A2A20`。
- 布局签名：圆角大卡片 + 图片带圆角 + 底部胶囊按钮；留白像度假页。
- 质感：圆角 20-28px，阴影暖而软，图标线稿 2px。
- 反例：陶土配亮蓝、通篇橙色、加粗边框。

## 6. 极地冰川 Polar Ice（金融 / 运动 / 工具）

- 情绪：精确、冷静、高性能。
- 字体：窄体/几何无衬线 display + tabular-nums 大数字。
- 配色：冰白 `#F4F8FA`，海军蓝 `#16283E`，冰青强调 `#3FB6A8`。
- 布局签名：大数字是绝对主角，图表极简，状态用细线图标。
- 质感：圆角 8-12px，边框 1px 冷灰，动效 150ms 内。
- 反例：彩虹图表、3D 立体按钮、暖色渐变。

## 7. 京都墨彩 Kyoto Ink（东方 / 文化 / 茶器香道）

- 情绪：禅意、留白、时间感。
- 字体：宋体/思源宋 display + 细黑正文。
- 配色：宣纸 `#F3EEE2`，墨 `#211D18`，朱砂 `#B23A2A`，金箔 `#C9A86A`。
- 布局签名：大量留白、竖排感（可用横排模拟）、印章式小元素、一行一物。
- 质感：圆角 2-6px，细线框，图片去饱和或同色系。
- 反例：鎏金渐变、满版装饰纹样、大红大绿。

## 8. 法式公寓 Paris Apartment（美妆 / 家居 / 内容社区）

- 情绪：温柔、精致、日常仪式感。
- 字体：衬线 display（优雅细衬线）+ 无衬线正文。
- 配色：奶油白 `#F6F1E7`，雾灰 `#D9D4C8`，鼠尾草 `#9CAF9A`，深可可 `#4A3B32`，千禧粉只作 5% 点缀。
- 布局签名：圆角卡片流 + 图片大圆角 + 组间距大于组内间距。
- 质感：圆角 20-24px，阴影极浅，图标细线 1.5px。
- 反例：粉紫渐变、蝴蝶结插画、糖果色堆叠。

## 9. 霓虹黑金 Neon Noir（潮流 / 3D / 游戏 / 音乐）

- 情绪：夜间、张力、未来感。
- 字体：压缩无衬线 display + 等宽数字。
- 配色：近黑 `#0D0F12`，霓虹青 `#35E0C3`，荧光橙 `#FF7A45` 只作 10%，冷灰 `#C8CFD6`。
- 布局签名：暗底发光焦点、大数字、3D/WebGL 场景就是主角。
- 质感：圆角 12px，发光只用一层（glow 或 blur 二选一），噪点纹理克制。
- 反例：彩虹霓虹、多层辉光、紫粉渐变。

## 10. 侘寂陶土 Wabi-Sabi（香氛 / 茶 / 器物 / 疗愈）

- 情绪：素、旧、静。
- 字体：衬线 display + 正文无衬线。
- 配色：灰褐 `#8B8178`，米白 `#F1EBE2`，陶土 `#A96B4B`，烟灰 `#3C3A37`。
- 布局签名：单物居中、图片占 70% 以上、一行小字说明。
- 质感：圆角 2-8px，粗粝纸感（低对比噪点），阴影几乎没有。
- 反例：亮橙 CTA、光滑渐变、现代感图标。

## 选风格的三分钟检查

1. 说出这套风格的一句情绪（"像什么环境里的一件东西"），说不出来就换。
2. 说出产品世界里自然存在的 3 个颜色，然后确认它们都在配方里。
3. 说出本页唯一的强调色用在哪个元素上。
4. 把风格名拿掉再看一眼：它像哪个 AI 模板？像，重来。

## 大厂气质：去体系库取结构，不凭印象模仿

当 brief 说"要苹果的感觉 / Stripe 的高级 / 微信的原生"，不要凭记忆画。读 [mature-systems-library.md](mature-systems-library.md)，里面有 Apple / Stripe / Linear / Vercel / WeChat / 小红书 / Material 的反解 token、字体、布局签名与"最适合/最不适合"。取签名与纪律，token 落进 design-tokens.json 后再写代码。

没有对应体系、想要快速定方向时，用 mature-systems-library.md 第 8 节的 Anthropic theme-factory 十套主题（4 色 + 字体 + 场景）做跳板，再用 palette.py 展开成完整色阶。

## 反 AI Slop 校准（所有配方共用）

AI 生成设计目前聚集在三个默认长相：

1. 暖奶油底 `#F4F1EA` + 高对比衬线 display + 陶土色强调；
2. 近黑底 + 单一荧光绿/朱红强调；
3. 通栏报纸风：发丝线、零圆角、密集分栏。

三个都可能正确，但只在 brief 明确要求时才允许。**自由轴上的选择，不花在默认上。** 完整 slop 速查、禁用字体与文案纪律见 [mature-systems-library.md](mature-systems-library.md) 第 9 节。

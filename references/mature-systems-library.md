# 大厂成熟体系库（Mature Systems Library）

<!-- ui-alchemy: ignore-all (this file intentionally documents production tokens, including pure black/white, as scan targets) -->

读于 Phase 1 定方向与 Phase 2 构建时。当 brief 想要"某个大厂的气质"时，不要凭印象模仿，直接读对应体系的反解 token、字体与签名，**取其结构方法，绝不抄视觉**。来源：OpenDesign 生产体系反解（Apple / Stripe / Linear / Vercel / WeChat / 小红书）、Anthropic theme-factory、cc-design 高保真规范。

## 0. 使用规则

1. **先对场景，再对体系。** 每个体系都写了"最适合什么、最不适合什么"，场景错配比抄得像更致命。
2. **一套体系 = 一整套承诺。** 圆角、边框、阴影、字重、间距全部继承该体系的纪律，不允许"苹果的排版 + Stripe 的紫 + Vercel 的阴影"混搭。
3. **token 全部落进 design-tokens.json**，再写代码。体系的 hex 只出现在本文件和 token 文件里，代码里只有语义 token。
4. **记住签名，而不是颜色。** 苹果的签名是"二元章节节奏 + 胶囊按钮"，Stripe 的签名是"300 细字重 + 品牌色相阴影"，抄到签名才叫学会。

## 1. Apple（媒体与消费 / 展示与交易双模式）

一句话气质：让界面消失，让产品与影像成为前景。

- 最适合：品牌官网、产品页、美妆/3C/生活方式、内容型 H5。
- 最不适合：数据密集型后台、政务/严肃工具。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| Hero 深场景 | `#000000` | 与浅场景交替构成章节节奏 |
| 浅画布 | `#F5F5F7` | 主浅色表面 |
| 墨色 | `#1D1D1F` | 主文字与深填充 |
| 纯白 | `#FFFFFF` | 零售/交易密度面 |
| 动作蓝 | `#0071E3` | 唯一动作色，链接 `#0066CC`，深场景链接 `#2997FF` |
| 次级文字 | `#6E6E73` | 说明与元信息 |
| 边框 | `#D2D2D7` / `#86868B` | 细分隔 / 强轮廓 |
| 石墨层 | `#272729` / `#262629` | 深色控制层 |

### 字体与层级

- Display 与 Text 双族；免费替代：标题 Inter Tight、正文 Inter（行高 +0.02 至 0.06，负字距收敛）。
- 字重阶梯以 600 为默认强调，700 少量，300 只在超大标题。
- 大标题负字距 -0.028em 至 -0.012em；正文行高 1.4 至 1.5。
- 层级：Hero 80/56px，章节 48px，产品 40px，卡片 28px，控制标签 14px，微 UI 12px。

### 布局与质感签名

- **二元章节节奏**：深黑章节与浅中性章节交替，而不是每一节同一种底色。
- **胶囊按钮语言**：主 CTA 8px 圆角，营销链接可以是整粒胶囊，圆形控件成组出现。
- **chrome 极薄**：层级靠对比与表面分离，不靠投影堆叠。
- **两档模式**：展示模式（大留白、cinematic）与交易模式（密集卡片、更小的间距）在同一套字体 DNA 下切换。
- 深度克制：阴影低而柔；色彩语义只有蓝色一种，错误/警告复用红色文字或图标。

## 2. Stripe（金融科技 / 技术感 + 高级感）

一句话气质：技术可信，同时豪华；深海军蓝标题 + 签名紫 + 300 细字重。

- 最适合：金融、支付、开发者平台、SaaS 官网、需要"昂贵技术感"的页面。
- 最不适合：生活化内容社区、儿童/娱乐消费。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| 白画布 | `#FFFFFF` | 页面底色 |
| 深海军蓝 | `#061B31` | 标题色，不是纯黑 |
| 签名紫 | `#533AFD` | 主 CTA 与交互，hover `#4434D4` |
| 品牌深蓝 | `#1C1E54` | 深色章节/页脚 |
| 正文 | `#64748D` | 次级文字 |
| 标签 | `#273951` | 表单标签 |
| 边框 | `#E5EDF5` | 默认分隔 |
| 紫边框 | `#B9B9F9` / `#D6D9FC` | 选中态 / 次级紫框 |
| 强调 | 红宝石 `#EA2261`、洋红 `#F96BEE` | 仅装饰与渐变点缀 |
| 成功 | `#15BE53` | 状态徽章 |

### 字体与层级

- 变量字体 300 字重做 display，是"不喊不吵的高级"；正文也常用 300 加 tabular-nums。
- 大标题负字距 -0.025em 至 -0.017em。
- 等宽：Source Code Pro 族做代码与技术标签。

### 布局与质感签名

- **多图层品牌色阴影**：`rgba(50,50,93,0.25)` + `rgba(0,0,0,0.1)` 双层，投影都带品牌蓝紫相。
- **圆角保守**：4 至 8px，没有任何胶囊。
- **轻字重排版**：300 大标题 + 深海军蓝，形成"低声权威"。
- 渐变只做品牌点缀（紫到洋红），主背景保持干净。

## 3. Linear（深色原生 SaaS / 精确工程感）

一句话气质：黑暗是原生介质，信息密度用白色不透明度分层，单一靛紫强调。

- 最适合：开发者工具、项目管理、深色优先的 SaaS、终端/数据产品。
- 最不适合：内容阅读型、消费电商。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| 营销黑 | `#08090A` | 最深画布 |
| 面板 | `#0F1011` | 侧栏/面板 |
| 提升面 | `#191A1B` | 卡片/浮层 |
| 二级面 | `#28282C` | hover 与更亮表面 |
| 主文字 | `#F7F8F8` | 偏暖的近白 |
| 次文字 | `#D0D6E0` | 银灰 |
| 三级 | `#8A8F98` | 元信息 |
| 四级 | `#62666D` | 时间戳/禁用 |
| 品牌靛 | `#5E6AD2` | CTA 底，交互用 `#7170FF`，hover `#828FFF` |
| 边框 | `rgba(255,255,255,0.05)` | 默认超细半透明边框 |
| 成功 | `#27A644` / `#10B981` | 仅状态点 |

### 字体与层级

- Inter Variable 开 `cv01` + `ss03`；签名字重 510（介于 regular 与 medium 之间）。
- display 负字距激进：72px 用 -0.022em，48px 用 -0.014em。
- 等宽：Berkeley Mono（回退 ui-monospace / SF Mono / Menlo）。

### 布局与质感签名

- **亮度阶梯**：背景从 `#08090A` 到 `#28282C` 逐级提亮，边框用白色透明度 0.05 至 0.08。
- **近零不透明按钮**：按钮底 `rgba(255,255,255,0.02)` 至 0.05，靠文字与边框定义。
- 整体系只有靛紫一个彩色；状态绿只出现在圆点。
- 阴影多层 + inset 变体，深色浮层用 `rgba(0,0,0,0.85)` 隔离。

## 4. Vercel（开发者工具 / 黑白精度 / Geist）

一句话气质：白底近黑字的画廊式空旷，每个像素都要挣来；阴影即边框。

- 最适合：开发者平台、技术博客、极简工具、作品集。
- 最不适合：需要温暖情绪或生活化场景的产品。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| 白画布 | `#FFFFFF` | 页面底色 |
| 近黑 | `#171717` | 主文字与深表面，非纯黑 |
| 灰 600 | `#4D4D4D` | 次级文字 |
| 灰 400 | `#808080` | 占位符 |
| 灰 100 | `#EBEBEB` | 边框 |
| 灰 50 | `#FAFAFA` | 微表面 |
| 链接蓝 | `#0072F5` | 链接与聚焦 |
| 工作流三色 | Ship `#FF5B4F` / Preview `#DE1D8D` / Develop `#0A72EF` | 流程步骤语义 |

### 字体与层级

- Geist Sans display 负字距极端：-0.033em 至 -0.04em，像压缩过的代码。
- 等宽 Geist Mono 全局开 `liga`。
- 免费替代：Inter / Space Grotesk 需要调校负字距后使用。

### 布局与质感签名

- **阴影即边框**：`box-shadow: 0 0 0 1px rgba(0,0,0,0.08)` 代替 border，圆角不裁切、过渡更顺。
- **多层阴影栈**：同一声明里 border 层 + 抬升层 + 环境层。
- 徽章用 9999px 胶囊 + 染色底。
- 状态色只在工作流步骤里出现，正文保持黑白灰。

## 5. WeChat 小程序体系（社交与服务 / 原生感）

一句话气质：干净、信任、平台原生；绿色是唯一品牌色，UI 靠中性灰分层。

- 最适合：微信小程序、服务号页面、社交/社区/生活服务。
- 最不适合：品牌个性极强的营销页（会被平台原生感吞掉）。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| 微信绿 | `#07C160` | CTA/选中态，hover `#10B160`，按下 `#059050` |
| 页面底 | `#EDEDED` | 小程序标准灰底 |
| 表面 | `#F7F7F7` | 卡片 |
| 边框 | `#E0E0E0` | 分隔 |
| 主文字 | `#1A1A1A` | ink |
| 次文字 | `#888888` | 时间戳/说明 |
| 危险 | `#FA5151` | 错误/删除 |
| 链接 | `#576B95` | 信息态 |

### 字体与层级

- 栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", Helvetica, Arial, sans-serif`。
- 页面标题 18/600，章节头 16/600，正文 15/400 行高 1.6，次要 13/400，说明 11/400。

### 布局与质感签名

- 4px 基准间距：xs 4 / sm 8 / md 12 / lg 16。
- 列表用"表面 + 分割线"而非阴影卡片；模态尽量用底部弹层。
- 按钮 16px 字重 500 行高 1.0；页面底色与卡片表面严格分开。

## 6. 小红书 XHS（生活方式 UGC / 内容优先）

一句话气质：UI 是透明相框，用户照片是颜色来源；单一品牌红，近乎无阴影。

- 最适合：内容社区、种草/生活方式、双列瀑布流、女性消费。
- 最不适合：B2B 后台、数据产品。

### Token

| 角色 | 值 | 备注 |
|---|---|---|
| 品牌红 | `#FF2442` | 唯一饱和色：tab 指示、点赞、主 CTA |
| 页面底 | `#F5F5F5` | canvas |
| 表面 | `#FFFFFF` | 卡片 |
| 透明填充 | `rgba(48,48,52,0.05/0.10/0.20)` | hover/按下/禁用，不造离散灰阶 |
| 分隔 | `rgba(0,0,0,0.08)` | 发丝线 |
| 标题 | `rgba(0,0,0,0.80)` | 软黑，绝不用纯黑 |
| 正文 | `rgba(0,0,0,0.62)` | 次级 |
| 说明 | `rgba(0,0,0,0.45)` | 辅助 |
| 深色表面 | `#19191E` | 微紫近黑，非纯黑 |

### 字体与层级

- PingFang SC 全链路，只允许 400/500/600 三个字重，无细体 display。
- 层级紧凑：H1 32/600，正文 14 至 16/400，tracking 0。
- 数字用专属等宽族对齐计数。

### 布局与质感签名

- **瀑布流不对齐**：图片高度驱动卡片高度，错位本身就是真实感。
- 圆角：卡片 12 至 16px，按钮全胶囊 9999px，底部弹层只圆顶部 16px。
- 阴影几乎为零，深度靠间距与圆角。
- 危险操作与主 CTA 同色时，用描边样式 + 图标区分意图。

## 7. Material（Android / 系统原生）

一句话气质：让 Android 用户感到"这是系统的一部分"，而不是 iOS 皮肤。

- Material 3 的 token：`primary` / `onPrimary` / `primaryContainer` / `surfaceContainer*` / `outline`。
- 签名：圆角 4/8/12/16/28 系统级、状态层（state layer 覆盖 8 至 16%）、高度 1 至 5 档、FAB、NavigationBar 3 至 5 项。
- 动态取色（Material You）只在系统开启时使用；自建主题时从品牌色生成 tonal palette，不要直接拿 hex。
- 触控目标 48dp；文字层级用 `display/headline/title/body/label` 五层体系。
- 详见 [platforms/app.md](platforms/app.md) 的 Android 段。

## 9. 反 AI Slop 校准（所有体系共用）

来自 Anthropic frontend-design 与 cc-design 的双重校准。AI 生成设计目前聚集在三个默认长相：

1. 暖奶油底 `#F4F1EA` + 高对比衬线 display + 陶土色强调；
2. 近黑底 + 单一荧光绿/朱红强调；
3. 通栏报纸风：发丝线、零圆角、密集分栏。

三个都可能是正确选择，但它们只在 brief 明确要求时才被允许。**自由轴上花掉的机会，不要花在默认上。**

### Slop 速查（命中即删，除非 brief 明确要求）

| 模式 | 替代 |
|---|---|
| 紫粉蓝全屏渐变 | 单色微妙渐变或纯色表面 |
| 圆角卡 + 左侧色条 | 背景/字重对比或细分隔线 |
| emoji 装饰（🚀✨） | 真实图标库或留空 |
| SVG 画人物/场景 | 灰占位框 + 标签，或真实图片 |
| 假数据/假评价 | 占位符或向用户索取真实数据 |
| 非必要的 bento 网格 | 按信息结构选布局 |
| 深色 slop（`#0D1117` + 霓虹） | 仅开发者工具类且有意为之 |
| glassmorphism 滥用 | 玻璃只做 accent |
| 扁平矢量角色插画 | 真实摄影或不用 |
| 无来源的四数字 stats | 有真实数据才放 |
| 三列同质 feature 卡 | 价值真的有差异才用 |
| New/Popular 徽章贴满 | 徽章只给真实例外 |

### 字体禁用与替代

- 默认禁用：Inter / Roboto / Arial / Fraunces / Space Grotesk 作为**唯一**字体。
- 正确姿势：serif + sans、mono + sans、或一个真正有性格的 display + 可靠正文的配对。
- 自由替代：Inter 只能当正文安全网，display 必须换有性格的字体；Roboto 用 Noto Sans SC 或系统字体栈替代；Space Grotesk 换 Outfit / Geist / Neue Montreal 类。

### 文案纪律（来自 Anthropic frontend-design）

- 文案是设计材料：控制按钮说它做的事（"保存更改"而非"提交"），动作名贯穿全流程（按钮"发布"产生 toast"已发布"）。
- 失败与空状态是方向不是情绪：说清发生了什么、怎么修，不道歉、不模糊。
- 用户语言优先：人们管理"通知"，不是"webhook 配置"；具体永远好过聪明。
- 主动语态默认；一句一职：label 只做 label，example 只做 example。

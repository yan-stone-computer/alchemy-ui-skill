# H5 / 移动网页最佳范式（Mobile Web Paradigms）

适用范围：移动端浏览器网页、公众号 H5、微信/支付宝内嵌 H5、响应式站点、PWA。

## Viewport 与安全区

- 必须声明：`<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">`。
- **禁止禁用缩放**：`user-scalable=no`、`maximum-scale=1` 会破坏可达性，是硬违规。
- 需要贴边沉浸时配合 `viewport-fit=cover` 使用 `env(safe-area-inset-*)`；底部固定操作条避开 Home Indicator。
- `theme-color` meta 跟随页面主色，深色模式切换。

## 布局与单位

- 移动优先；全屏容器用 `min-h-[100dvh]`，禁用 `h-screen`。<!-- ui-alchemy: ignore -->
- 弹性字体：`font-size: clamp(16px, 4vw, 20px)` 或 rem 方案，避免固定 px 字号在系统字体缩放下截断；`-webkit-text-size-adjust: 100%`。
- 断点一致（640 / 768 / 1024），每个多列布局显式声明 < 768px 折叠方式。
- 触控目标 >= 44px；`:active` 按下反馈；hover 只能作为增强，不能是唯一入口（`@media (hover: hover) and (pointer: fine)`）。

## 性能预算（Core Web Vitals）

- **LCP < 2.5s**：LCP 图预加载（`<link rel="preload" as="image">` 或 `next/image priority`），图片带 `width`/`height` 或 `aspect-ratio` 预留空间。
- **INP < 200ms**：长任务拆解，滚动/交互动画只动 `transform`/`opacity`，禁 `window.addEventListener("scroll")`。<!-- ui-alchemy: ignore -->
- **CLS < 0.1**：图片、字体（`font-display: swap` + 子集）、广告位全部预留空间。
- 懒加载首屏以下图片（`loading="lazy"` + `srcset`/`sizes`）；JS 按路由拆包；骨架屏替代全屏 loading。

## 深色模式与主题

- `prefers-color-scheme` + CSS 变量（语义 token），跟随系统；品牌色在两种模式下都可识别。
- 首屏绘制前就设置好 `color-scheme` 与 `theme-color`，避免白屏闪烁。

## 交互与可达性

- 语义 HTML、真实 `<button>`/`<a>`/`<input>`、`alt`、ARIA；键盘可操作；焦点可见。
- 表单：label 关联、错误内联、`inputmode` 正确；避免 placeholder 当标签。
- 动效尊重 `prefers-reduced-motion`；滚动揭示用 IntersectionObserver 或 CSS scroll-driven animations。
- 微信/支付宝内嵌场景：注意 JSSDK ready 时序、分享与支付回调、`WeixinJSBridge` 兼容；弱网降级（超时、重试、离线提示）。

## 交付前检查

1. `--platform h5` 扫描清零（viewport 缺失、禁用缩放、`h-screen`、`transition: all` 等）。<!-- ui-alchemy: ignore -->
2. 375 / 414 / 768 / 1440 四档宽度过一遍；无横向滚动、无截断、无触控误触。
3. 3G 弱网与系统字体放大 200% 下各验证一次。
4. Lighthouse 移动端跑分：LCP / INP / CLS 达标。

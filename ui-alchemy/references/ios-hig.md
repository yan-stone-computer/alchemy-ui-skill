# iOS 美学与导航基准（Apple-Grade UI & HIG）

<!-- ui-alchemy: ignore-all (this file intentionally documents pure black/white tokens from HIG as scan targets) -->

读于任何 App / 小程序 / 移动 H5 的构建或打磨阶段。目标是"像苹果一样好看"：不是照抄 iOS 组件，而是拿到 Apple 判断设计的那套尺子：导航永远在场、层级永远可读、每个状态都被考虑过。

## 1. 导航架构是硬要求（先于审美）

没有导航系统的 App 是半成品。任何多页面的移动端交付物必须有一个可见、一致、可达的导航层，三者取一：

| 导航层 | 何时用 | 铁律 |
|---|---|---|
| Tab Bar（底部标签栏） | 2-5 个同级一级入口 | 图标+文字，选中态明确；当前页高亮；切换不丢状态 |
| Navigation Bar（顶部导航栏） | 层级页面的标题与返回 | 返回永远可达；标题 = 当前上下文；右侧最多一个主操作 |
| Segmented / Picker | 同一页内的视图切换 | 作为二级切换，不替代 Tab Bar |

判分问题：把页面截图给陌生人，他能在 3 秒内说出"我在哪、能去哪、怎么回去"吗？不能就重做导航。

## 2. 苹果式细节清单（逐条过）

- **层级三杠杆**：同一字号用字重（600/500/400）+ 颜色（primary/secondary/muted）分出三层，不靠字号轰炸。
- **大标题**：一级页用大号粗体标题（约 34pt）撑起首屏；进入二级页自动变成小标题+返回。
- **分组列表**：设置/资料类页面用圆角分组卡片（inset grouped），组间距大于组内间距，行高约 44-56pt。
- **留白优先于分割线**：能靠间距分组的，不用线；必须用的线用 0.5-1px 低透明度。
- **材质与模糊**：导航栏/悬浮条用半透明材质（`backdrop-filter` / `ultra-thin material`），内容滚动时透出层次，而不是死色块。
- **圆角与密度**：大卡片 20-28px，控件胶囊形或 10-14px；触控目标 ≥ 44pt，间距落在 4/8 网格。
- **数字与数据**：`tabular-nums`，大数字是本页主角时给足字号与留白；单位用 muted 色靠后。
- **动效**：转场 200-350ms，`cubic-bezier(0.32, 0.72, 0, 1)`（iOS 曲线）；只动 transform/opacity；系统级交互动效（列表惯性、按压缩放）优先于自造动画。
- **反馈**：点击有按压态；关键操作有触觉反馈（Haptic）；禁用态不是"变灰"，而是明确的 disabled 视觉。
- **语义化图标**：图标用同一家族、同一描边/填充权重；纯图标必须有文字或标签语义。
- **安全区**：刘海、Home Indicator、灵动岛均不遮挡内容；底部固定栏避开 `env(safe-area-inset-bottom)`。
- **深色模式**：语义 token 双套；材质与阴影在深色下重新校准，不能只是反色。
- **状态齐全**：loading / empty / error / offline 都有设计，不裸奔。

## 3. 视觉审查（苹果视角）

1. 截当前屏，问：第一眼焦点是什么？如果答不出，重做层级。
2. 问：这页需要滚动吗？需要的话，导航与主操作是否常驻可及。
3. 问：删掉所有边框和装饰色，层级还在吗？在，说明设计成立；不在，说明靠装饰撑场。
4. 问：把图标换成 SF Symbols 风格描边，页面还协调吗？不协调说明图标系统没统一。
5. 问：字号放大 120%、深色模式、弱网下，这页还成立吗？

## 4. 反"伪苹果"

- 不是堆圆角和毛玻璃就苹果了；苹果的干净来自**决策密度**：每个元素为什么存在。
- 不是所有页面都要大标题；工具页用紧凑标题，浏览页用大标题。
- 不做纯白 `#fff` 纯黑 `#000`；苹果的"白"是带温度的表面色。
- 不用 emoji 当图标，不用默认紫渐变，不用三等宽卡片。

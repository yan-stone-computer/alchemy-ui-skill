# Apple 级布局系统（Layout System Spec）

<!-- ui-alchemy: ignore-all (documents exact spacing/type values; tokens appear as scan targets) -->

读于 Phase 1 定方向后、写代码前。目标：布局"一眼高级"，不是"结构正确"。原则文档到处都是，这里给的是**可以直接照抄的数字与模板**。

## 0. 高级布局三问（先自问再动手）

1. 眯眼看截图：第一个焦点是什么？3 秒内能不能说出这页在卖什么？
2. 换皮测试：换成任何别的产品，这页还成立吗？成立就是没做选择。
3. 留白测试：信息之间有呼吸吗？密区让位疏区了吗？全屏一样密 = 没人做过决定。

## 1. 8pt 基础网格（全站唯一单位制）

- 间距、圆角、卡片尺寸一律 8 的倍数；4 只用于 1px 级微调（边框、细线）。
- 卡片 padding：24px（密）或 32px（呼吸），同一页只选一档并贯彻。
- section 间距：96 至 128px（桌面），72 至 84px（移动）。
- 圆角系统（一套到底）：卡片 16 / 22 / 28，图片 24 至 32，按钮胶囊 999px。
- 行高：正文 1.5 至 1.6，标题 1.04 至 1.15，大标题 1.02 至 1.06。

## 2. 字号阶梯（Apple 基准，直接抄）

| 角色 | 桌面 | 移动 | 字重 | 行高 | 字距 |
|---|---|---|---|---|---|
| Hero Display | 72 至 84 | 44 至 52 | 800 | 1.04 | -0.02em |
| Section Title | 40 至 48 | 30 至 36 | 800 | 1.1 | -0.015em |
| Card Title | 20 至 24 | 18 至 20 | 700 | 1.25 | 0 |
| Body | 16 至 17 | 15 至 16 | 400 | 1.6 | 0 |
| Secondary | 14 | 13 | 400 | 1.5 | 0 |
| Meta / Label | 12 至 13 | 11 至 12 | 500 | 1.4 | 0.02em |

- 层级三杠杆：字号 + 字重 + 颜色，永远不只用字号。
- 数字一律 `font-variant-numeric: tabular-nums`。
- Hero 标题控制在 2 行内，副文案 20 词内、4 行内，CTA 首屏可见。

## 3. Section 节奏模板（四种轮换，全页必须有变化）

全页禁用同一种 section 布局。四种模板轮换，相邻两个 section 不用同款：

1. **Hero**：kicker（13px 大写 0.24em 字距）+ 大标题 + 副文案 + CTA 一实一虚 + 主视觉图。居中或左对齐二选一，主视觉大而真实。
2. **Split**：左文右图（或反），图占 55 至 60%，文字垂直居中，间距 40 至 64px。
3. **Gallery**：网格或横向滚动，卡片宽度相同但内容有主次（featured 卡放大 1.5 倍或色块区分）。
4. **Film**：sticky 滚动叙事（产品 3D 电影），见 [scroll-film-spec.md](scroll-film-spec.md)。

至少 4 种内容板块的页面，布局家族必须 >= 3 种；宁可砍内容也不重复排版。

## 4. 留白公式（直接抄）

- section 上下 padding：桌面 110 至 130px，移动 72 至 84px。
- section 标题区与内容间距：40 至 48px。
- 卡片间距：16 至 20px（密集档）或 24 至 32px（呼吸档）。
- 导航高度：64px（桌面）/ 52 至 56px（移动），吸顶 + `backdrop-filter: saturate(1.4) blur(18px)` + 半透明底 + 1px 发丝线。
- Hero 内容上边距：96 至 120px；主视觉下边距 48 至 64px。
- 页脚：border-top 1px 发丝线 + 42 至 48px padding。

## 5. 高级 vs 廉价（反模式表，命中即改）

| 廉价（AI 默认） | 高级替代 |
|---|---|
| 三等宽卡片排满一行 | 不对称网格、featured 放大、或横向滚动 |
| 每一节都同一种布局 | 四种节奏模板轮换 |
| 卡片套卡片（nested cards） | 平级区块 + 发丝线分割 |
| 全屏统一密度 | 密区让位疏区，节奏有起伏 |
| 标题 + 副标题 + 按钮三件套反复出现 | 每节一个记忆点，不重复同构 |
| 全部居中或全部左对齐 | 有左有中，节奏与重点变化 |
| 信息挤满首屏 | Hero 只放标题、一句话、一个 CTA、一张图 |
| 8px 外的随机间距（13 / 17 / 26px） | 全部落在 8pt 网格 |
| 大量边框包裹内容 | 先靠留白与色阶分层，边框是最后手段 |

## 6. 验收

- 眯眼测试：焦点唯一、无刺眼跳出。
- 网格审计：所有间距能被 8 整除（允许 4 的边框微调）。
- 节奏审计：相邻 section 布局不重复；8 个板块至少 3 种布局家族。
- 比例审计：图片卡、标题、正文的比例符合阶梯，没有孤立的奇怪字号。
